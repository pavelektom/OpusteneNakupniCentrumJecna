# 🏢 **Opuštěné nákupní centrum Ječná**

### **Autor**
*Tom Pavelek*

## 📓 Popis hry
Tomáš se probouzí na studené dlažbě nákupního centra, 
které bylo už dlouhá léta zpět opuštené, kvůli nějaké systémové vadě,
která tu uzavřela do teď několik zaměstnanců, Vaším úkolem je,
zprovoznit bezpečnostní systém a tím odemknout nákupní centrum.

## 💡 Příkazy
`jdi <místnost>` → **přesun mezi místnostmi  
`mluv <postava>` → **zahájí dialog**  
`ukoly` → **zobrazí úkoly hráče a jestli jsou splněné či ne**  
`prozkoumej` → důkladné prohledání místnosti**        
`hledat` → **vypíše, co viditelné je v místnosti**  
`vezmi <predmet>` → **vezme předmět (pokud je viditelný)**  
`pouzij <predmet>` → **použije předmět z inventáře**  
`odemkni <místnost>` → **odemkne zamčenou místnost**  
`inventar` → **zobrazí obsah inventáře**  
`napoveda` → **zobrazí nápovědu**  
`pomoc` → **vrátí všechny dostupné příkazy**  
`konec` → **ukončí hru**  
`poloz <predmet>` → **položí předmět na zem do místnosti, ve které se nachází hráč**

## 🧐 Jak hru spustit
 #### Hra je hraná pomocí konzole jako textová hra  
1. **Musíte** mít nainstalovaný **jar** soubor s hrou.
2. Otevřete terminál ujistěte se, že máte správnou cestu k dokumentu
3. Za dokument napište java -jar (jméno souboru)
4. **Hrajte :D**
